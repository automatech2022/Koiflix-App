## ✨ Features

- 🎬 **Streaming sin interrupciones:** Catálogo gigantesco actualizado con las mejores series, películas y capítulos en emisión.
- 👤 **Perfiles Múltiples:** Mantén tu historial, tu lista de favoritos y tus preferencias separadas para cada integrante.
- 📌 **Widget de Inicio "Continuar Viendo":** Retoma tu anime favorito exactamente donde lo dejaste, directamente desde la pantalla de inicio de tu celular.
- 🔍 **Búsqueda Inteligente:** Motor de búsqueda tolerante a errores, encuentra tus animes favoritos rápido y sin esfuerzo.
